# Better-ruins
Makes the ruins in the game more powerful
V2.2
Leave a star if you like it. I will appreciate weigthing suggestions.
Includes fixes from Momo630 for games with religion disabled, so that faith yields and pantheon based restrictions don't apply.

His fork also applies a workaround for a suspected AI unit-swap/ruin side effect in Unciv 4.22.16. Its effect on the reported crash has not been verified.
Check his fork out [here](https://github.com/Momo630/Better-ruins) and download from there using the link should this problem be relevant to you. More details are found in his README.
